# Repository Guidelines

This repository (`pravinraj213/low-code-zoho-creator`) serves as the coursework archive for **CB23F35: Low-Code Application Development using Zoho Creator**.

---

## File Naming Conventions

* **PDF Documents/Reports**: `Exp<Num>_<Title>.pdf`
  * *Example*: `Exp1_Comparative_Study.pdf`
  * *Example*: `Exp4_Data_Modelling.pdf`
* **Deluge Scripts / Configurations**: `Exp<Num>_<Title>.<ext>`
  * *Example*: `Exp6_Workflows.ds`

---

## Report Structure (Experiments 4 to 15)

All experiment reports starting from Experiment 4 must strictly follow this internal structure:

1. **Aim**: Clear and concise statement of the experiment's goal.
2. **Procedure**: Detailed step-by-step procedure, including setup instructions, CLI commands, script snippets, and UI navigation steps, accompanied by **screenshot placements/captions**.
3. **Output**: Screenshots or code logs demonstrating the final working output in Zoho Creator.
4. **Result**: Summary statement confirming successful completion of the experiment against its objectives.

## Commit & Workflow Rules

1. **Only PDFs Allowed for Final Uploads**: Do not commit intermediate document generation files (`.docx`, `.md`, templates, etc.) or agent configuration artifacts. **Only final compiled `.pdf` reports and source `.ds` scripts should be committed and uploaded.**
2. **Clean Commit Messages**: Use clear messages formatted as:
   * `docs: upload Exp<Num> report`
   * `feat: add Exp<Num> deluge script`
